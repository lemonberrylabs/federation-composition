# federation-composition-rs

A Rust port of [`@theguild/federation-composition`](https://github.com/graphql-hive/federation-composition), the Apollo Federation v1/v2 schema composition library by [The Guild](https://the-guild.dev). Given a set of subgraph schemas, it validates them and composes the supergraph schema, with the same output and error messages as the TypeScript library.
