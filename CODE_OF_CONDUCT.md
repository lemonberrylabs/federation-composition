# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text, at that link, is this project's code of conduct, and it applies in every project
space: issues, pull requests, discussions, and any other place where you represent the project.

## Reporting

Report unacceptable behavior to the maintainer, [@Enrico2](https://github.com/Enrico2), at the
email address on that GitHub profile, or privately through GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature. Reports are reviewed promptly and kept confidential. The maintainer enforces the code
of conduct following the Covenant's enforcement guidelines (correction, warning, temporary ban,
permanent ban).
